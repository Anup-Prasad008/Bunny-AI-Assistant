BUNNY AI • PROJECT OVERVIEW

About Bunny AI

A friendly AI workspace built to make learning, creating and everyday digital work feel simpler.

Made by Anup PrasadGemini-poweredPython + FastAPILearning-focused project

Here is an honest overview of what the current project provides and what is still planned. Roadmap items are not presented as working features.

Available in the current project

💬 AI conversations

Ask questions and get Gemini-powered responses through the Bunny backend. The interface is designed for Hindi, Hinglish and English prompts.

🧮 Calculations

Assistant support for everyday maths, BODMAS-style expressions and number-system conversions.

🧠 Conversation memory

Session-based conversation history and memory endpoints, with recent chats saved in the browser.

🎙️ Voice input

Browser speech recognition can turn spoken prompts into text before sending them to Bunny.

🔗 Helpful actions

Responses can include safe web links and supported assistant actions. The README also documents search, weather and music-style prompts.

🔐 Accounts & appearance

Firebase authentication UI, responsive workspace, chat history and light/dark appearance controls.

Planned / coming soon

📎 File attachments

Upload and ask questions about PDFs, images, documents and spreadsheets.

🖼️ Image & video tools

Image generation, image understanding and video-related workflows.

📚 Personal library

Organize useful files, saved outputs and reusable project materials.

🔌 Personal API settings

Per-user Gemini API key management after the backend is updated to support it securely.

Availability can depend on the deployed backend version and its environment settings. Some roadmap ideas may change as development continues.

Bunny connects to Google Gemini through its Python FastAPI backend. The current deployed backend reads one Gemini key from its server environment; it does not currently accept a different API key from each website user.

Backend v2.2.0 — API foundation and reliability

The current backend is built with Python and FastAPI. It provides the service layer that connects the Bunny interface to the Gemini-powered assistant while keeping the Gemini credential on the server instead of exposing it in browser code.

Highlights in this backend version:

  • Health and service checks: root and /api/health endpoints report whether the backend is online and whether a Gemini key is configured.
  • Gemini configuration: the backend reads GEMINI_API_KEY from the hosting provider's environment variables. The key is not sent to the frontend.
  • Conversation endpoint: POST /api/chat accepts a message and optional session ID, then returns Bunny's reply and any supported action data.
  • Session separation: Bunny instances are maintained per session, and a per-session lock helps prevent overlapping requests from interfering with the same conversation.
  • Memory and session controls: routes are available to read session memory, clear a session's history and memory, or delete a session.
  • Request validation: request models validate incoming data and apply message and session identifier limits.
  • Deployment safeguards: configurable CORS origins, non-wildcard defaults and user-safe error responses help keep the API deployment more controlled.

Current frontend — authentication and chat workspace

The frontend brings sign-in, chat and account controls together in a responsive single-page interface. It is designed to work on desktop and mobile browsers, with the backend URL and Firebase web configuration supplied by the project owner.

  • Firebase authentication: the interface includes account sign-in and registration flows supported by the configured Firebase project.
  • Chat workspace: users can start a conversation, send prompts, view responses and follow the assistant's loading and error states.
  • Conversation history: recent conversations are presented in the sidebar and can be reopened from the workspace.
  • Account and appearance controls: account options and light/dark theme controls are available from the interface.
  • Voice input: supported browsers can use speech recognition to convert spoken prompts into text before sending.
  • Response handling: the interface connects to the FastAPI chat endpoint and supports loading, stop-generation and error feedback states.
  • Header information windows: About, Features, API, Releases and Pricing open in their own in-page popup rather than navigating away from the chat.

Assistant capabilities documented in the project

Bunny's assistant layer is intended to help with everyday questions and practical learning tasks. Depending on the active backend implementation and configuration, the project documents support for:

  • Natural-language conversations and explanations.
  • Everyday calculations, BODMAS-style expressions and number-system conversions.
  • Session-based conversational context and memory.
  • Helpful web links and supported assistant actions.
  • Prompts related to information search, weather and music discovery where the corresponding action is available.

Planned work — future development

The following items are roadmap ideas, not claims about features already active in the current deployment. They will be marked as available only after the required frontend and backend work has been completed and released.

  • File and document understanding: upload support for common document and image formats, followed by question-answering over the uploaded content.
  • Expanded multimodal tools: image understanding, image generation and additional media workflows.
  • Personal API settings: a secure per-user Gemini API key flow, including backend validation and safe handling. A frontend-only key field is not sufficient.
  • Personal library: a place to organize saved files, useful responses and reusable materials.
  • More assistant tools: additional productivity actions and clearer controls for managing which tools are enabled.
  • Release transparency: versioned notes that identify what changed, what is still experimental and what is available in the deployed build.
